# 새결 브랜드 자산

이 폴더의 파일은 새결(Team Saegyeol)의 상표이며 **코드 라이선스(Apache-2.0)에
포함되지 않습니다.** 자세한 조건은 저장소 루트의 [NOTICE](../../NOTICE)를 보세요.

| 파일 | 용도 | 크기 |
|---|---|---|
| `saegyeol-logo-vertical.png` | 세로형(심볼 + SAEGYEOL). README 상단, 앱 정보 화면 | 폭 600px |
| `saegyeol-symbol.png` | 심볼 단독. 파비콘, 작은 자리, 내보내기 표시 | 폭 128px |

## 사용 규칙

- 심볼 색: `#0F2742` (새결 네이비)
- 로고 둘레에는 심볼 지름의 1/2 이상 여백을 둡니다.
- 형태·비율·색·파도 방향을 바꾸지 않습니다. 늘이거나 기울이지 않습니다.
- 단색 밝은 면(흰색 또는 `#F5F8FB`) 위에 올립니다.
- 포크할 때는 이 파일들을 본인/본인 조직의 로고로 교체해야 합니다.
