# 화면 규칙

Stage Planner의 화면을 만들 때 지키는 규칙입니다. 색 값은 코드에 직접 쓰지 않고
`src/styles/tokens.css`의 토큰을 씁니다(1단계 이후 `packages/app/src/styles/tokens.css`).

새결 디자인 원본 문서는 이 저장소에 넣지 않습니다. 이 문서와 토큰 파일만 둡니다.

---

## 색

| 이름 | 값 | 쓰임 |
|---|---|---|
| navy | `#0F2742` | 제목, 본문, 주요 버튼 배경 |
| deep | `#081A2E` | 어두운 배경 |
| tide | `#2563C4` | 링크, 선택, 포커스, 강조 |
| surface-blue | `#6FA3E8` | 어두운 배경 위 강조 |
| foam | `#F5F8FB` | 페이지 배경 |
| mist | `#E3EAF2` | 구분선, 카드 테두리 |
| slate | `#56667A` | 보조 텍스트, 캡션 |
| signal | `#C8323A` | 긴급·위험 |

다크 모드

| 토큰 | 값 |
|---|---|
| 배경 | `#081A2E` |
| 표면 | `#0F2742` |
| 본문 | `#E3EAF2` |
| 보조 | `#9AAABD` |
| 테두리 | `#1E3A5C` |
| 강조 | `#6FA3E8` |
| 위험 | `#FF6B6B` |

- **설계 화면(무대 설계, PA 조언, 타임테이블, 시작하기)은 라이트가 기본**입니다.
- **운영 화면(대시보드, 대기실 공지)은 다크가 기본**입니다. 공연장이 어둡기 때문입니다.
- 둘 다 수동으로 바꿀 수 있고, 따로 정하지 않으면 기기 설정을 따릅니다.
- **시그널 레드는 한 화면에 한 곳만** 씁니다. 긴급 공지와 삭제 같은 위험한 동작에만 씁니다.
  장비 구분을 빨강이나 무지개 색으로 하지 않습니다.

## 글자

- 서체는 **Pretendard 서브셋**(한글 완성형 + 영문·숫자)을 앱에 포함해 씁니다.
  인터넷 없이 동작해야 하므로 외부에서 내려받지 않습니다. 표시 화면을 태블릿에서
  빨리 띄우는 것이 중요하므로 가변 폰트 전체(약 2MB)는 쓰지 않습니다.
- 숫자는 `font-variant-numeric: tabular-nums`로 자리를 맞춥니다. 표와 남은 시간에 필수입니다.
- 한국어는 어절 단위로 줄을 바꿉니다: `word-break: keep-all; overflow-wrap: break-word;`
- 표시 화면(대기실·스태프·큐)은 멀리서 읽히도록 아주 큰 글씨를 씁니다.

## 모양과 간격

- 반경: 버튼·입력창 8px, 카드 12px, 모달 16px
- 간격은 4px 단위(4, 8, 12, 16, 24, 32, 48, 64)
- 그림자는 떠 있는 요소(모달, 드롭다운, 토스트)에만: `0 8px 24px rgba(15,39,66,.12)`
- 평면 카드는 그림자 대신 테두리 1px로 구분합니다.

## 터치

- 터치 영역은 **44px 이상**입니다.
- 캔버스에는 `touch-action: none`을 걸고 Pointer Events로 직접 처리합니다.

## 문구

- **합니다체**로 씁니다. 해요체는 쓰지 않습니다.
- 버튼과 메뉴는 **명사형**으로 씁니다: "공지 보내기", "순서 시작", "저장".
- 오류는 사과하지 말고 **원인과 해결**을 말합니다.
  예: "접속 코드가 맞지 않습니다. 호스트 화면의 코드를 확인해 주세요."
- 쉬운 말로 씁니다. 겁주지 않습니다.
- **UI에 이모지를 쓰지 않습니다.** 아이콘이 필요하면 선형 아이콘이나 글자를 씁니다.

## 로고

- 새결 로고는 저작권 표시용으로 **앱 정보 화면, README, 내보내기 파일 하단**에만 넣습니다.
- 형태·비율·색을 바꾸지 않습니다. 둘레에 심볼 지름의 1/2 이상 여백을 둡니다.
- 로고는 코드 라이선스에 포함되지 않습니다. 자세한 조건은 [NOTICE](../NOTICE)를 보세요.
