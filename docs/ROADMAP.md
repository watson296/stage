# 로드맵

이 문서는 앞으로 할 일의 계획입니다. 1~2단계(레포 정리, 기반 전환)는
끝났습니다. 아래는 3단계 이후 계획이며, 아직 구현하지 않았습니다.

## 1단계 — 레포 정리 (완료)

- `.gitignore` 추가, 생성물·개인 경로 제거
- 로고를 `assets/brand/`에 정리, Apache-2.0 라이선스와 문서 추가

## 2단계 — 기반 전환 (완료)

- 순수 HTML·Canvas → Vite + TypeScript(프레임워크 없음), 테스트는 vitest
- 미터 월드 좌표, 단일 축척, 회전 사각형 히트테스트, Pointer Events(터치·핀치)
- devicePixelRatio 반영, 되돌리기/다시 실행, IndexedDB 자동 저장
- JSON 스키마 버전(v1)과 마이그레이션, 불러오기 검증
- 기능은 1단계와 동일하게 유지

---

## 3단계 — 디자인 시스템과 터치 UI

- 새결 디자인 시스템 적용 (`src/styles/tokens.css`의 토큰 사용, Pretendard 글꼴)
- 터치 우선 UI
  - 하단 트레이(장비 목록)
  - 오브젝트 선택 시 뜨는 도구줄
  - 하단 시트(속성 편집)
  - 모든 터치 영역 44px 이상
- 다크 모드(기기 설정 따르기 + 수동 전환)

## 4단계 — 공연장 기능

- 동일 축척 표시와 거리 재기
- 무대 템플릿과 편성 프리셋
- 공연장 사진·도면을 밑그림으로 깔고 축척 맞추기
- 입력 리스트(채널 리스트) 자동 생성
- 레이어
- PDF 내보내기
- 기획 모드와 현장 모드

### 4-2. 음향 계산 도구

`src/audio/`에 **순수 함수**로 구현하고 vitest로 검증합니다. 각 함수는 단위와
가정을 명시합니다.

- 거리 감쇠 (역제곱 법칙)
- SPL 추정
- 음원 합산 (여러 음원의 합성 SPL)
- 지연 시간 (음속, 온도 보정 포함)
- dBu ↔ dBV 변환
- 임피던스 계산
- 케이블 손실
- 전원 용량 점검
- 채널 수 점검

### 4-3. 배치 연동 계산과 커버리지 표시

- 배치된 스피커 위치에 4-2 계산을 연동
- 스피커 지향각·커버리지 표시
  - **직접음만 계산하는 추정**이며, 이 점을 화면에 명시합니다.
  - 반사·실내 음향은 포함하지 않습니다.
  - 제조사 데이터는 내장하지 않고 사용자가 입력합니다.

## 5단계 — 문서화와 공개 준비

- 사용자 문서, 스크린샷
- 공개 준비(이슈 템플릿, 릴리스 노트)
- 개발 보조용 mods (선택)
