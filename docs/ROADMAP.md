# 로드맵

Stage Planner를 "공연 준비 + 공연 당일 운영" 도구로 넓히는 계획입니다.
기능 명세는 [SPEC.md](SPEC.md), 화면 규칙은 [design.md](design.md)를 보세요.

단계마다 브랜치를 만들어 작업하고, 끝나면 보고하고 멈춥니다.

---

## 끝난 일

### 레포 정리 (완료)

- 대용량 생성물(`stage-planner.html`, `logo_b64.txt`)과 빌드 스크립트(`gen.py`),
  개인 PC 경로가 든 설정 파일을 추적에서 제거
- `.gitignore`, `LICENSE`(Apache-2.0), `NOTICE`, `README`, `CONTRIBUTING` 추가
- 로고를 `assets/brand/`에 정리(세로형 600px, 심볼 128px, 심볼색 #0F2742 확인)

### 기반 전환 (완료)

- 순수 HTML·Canvas 한 파일 → Vite + TypeScript(프레임워크 없음), 테스트는 vitest
- 미터 월드 좌표, 단일 축척(무대 비율 왜곡 제거)
- 회전은 `rot` 하나만 두고 w/d를 맞바꾸지 않음. 회전 사각형 기준 히트테스트
- Pointer Events로 마우스·터치·펜 통합, 두 손가락 이동·핀치 줌
- devicePixelRatio 반영, 명령 단위 되돌리기/다시 실행, IndexedDB 자동 저장
- JSON `version: 1` + 불러오기 검증 + 옛 형식 변환

## 1단계 — 모노레포와 공용 스키마 (완료)

- `packages/app`(프런트), `packages/server`(호스트 서버), `packages/shared`(스키마·계산·메시지 타입)
  로 나눕니다. 지금 `src/`는 `packages/app/src`로 옮기고, 모델·계산은 `shared`로 뺍니다.
- 공용 데이터 스키마(v2)와 검증기를 `shared`에 만듭니다.
- **v1 → v2 변환**을 테스트와 함께 만듭니다(SPEC 5.1).
- Preact + @preact/signals를 넣고 화면 틀을 잡습니다. 캔버스는 지금처럼 직접 그립니다.
- 기존 기능과 테스트가 그대로 통과해야 합니다.

## 2단계 — 무대 설계 (완료)

- 다각형 무대와 템플릿 7종(사각 / 앞이 둥근 / 돌출 / 원형 / 중앙 / L자 / 날개)
- **원호(`ArcSegment`)**: 변 중점 손잡이를 끌어 곡선을 만들고, 더블탭으로 직선으로
  되돌립니다. 앞이 둥근 무대와 원형은 점을 잘게 찍지 않고 원호를 씁니다
  (24점 → 꼭짓점 4개 + 호 1~4개).
- 꼭짓점 편집: 끌어 옮기기, 탭해서 고르고 지우기, 좌표 숫자 입력.
  꼭짓점을 지우면 원호 번호를 다시 맞춥니다.
- **구역(`Zone`) 6종**: 라이저·단차(높이 입력), 객석·FOH·출입구·대기실 동선.
  끌어 사각형으로 만들고 꼭짓점으로 고칩니다. 구역 표시 끄기/켜기.
  장비가 라이저 위면 속성 바에 표시합니다.
- 객석 방향(앞쪽 / 사방), 무대 밖 배치(FOH, 객석 스택)
- 장비 그림 15종을 파라메트릭 코드로(`packages/shared/src/draw/shapes.ts`), 분류색 3색
- 크기·회전 손잡이, 규격 고르기, 숫자 입력, 스냅
- 무대 모양을 선분으로 펴는 `tessellate` 하나로 그리기·히트테스트·경계 제한·
  내보내기를 모읍니다. 경계 제한은 장비 중심 기준입니다(SPEC 11장).
- PNG 내보내기와 PDF(브라우저 인쇄 + print CSS, 라이브러리 없음). 범위는
  무대 + 구역 + 무대 밖 장비를 합친 것이고, 하단에 새결 로고가 들어갑니다.
- Pretendard 서브셋 글꼴 포함(한글 완성형 + 영문·숫자, 굵기 셋)
- UI에서 이모지 제거

## 3단계 — PA 조언 (완료)

- `packages/shared/src/audio`에 순수 함수로 계산을 만들고 알려진 값과 대조
  (음속·온도 보정, 지연 시간, 거리 감쇠, SPL 추정, 음원 합산, dBu/dBV, 전원 전류)
- 공연장 정보·편성·스피커 제원 입력 화면과 결과 화면.
  **근거 문장과 가정·한계를 결과 옆에 함께 표시**합니다.
- 입력 채널 리스트 초안(번호·소스·마이크·스탠드)과 준비물 합계, 믹서 채널 점검
- 전원 합계와 회로 점검(회로당 80% 기준)
- 스피커 제원 프리셋을 기기에 저장(`localStorage`). 고른 제원은 공연 파일에 복사합니다
- 결과를 도면에 **배치 초안**으로 넣기(되돌리기 한 단계로 취소)
- 화면 탭(무대 설계 / PA 조언) 추가

남은 것

- 스피커 지향각으로 커버리지 범위를 도면에 그리기. 숫자로는 내지만 아직 그리지 않습니다.
- 임피던스·케이블 손실 계산. 액티브 스피커를 기준으로 삼아 미뤘습니다.

## 4단계 — 타임테이블 (완료)

- 항목 편집(리허설, 사운드체크, 공연, 전환, 휴식, 기타), 위아래로 순서 바꾸기
- 담당·메모·무대 도면 연결
- 시작·종료 기록. 한 번에 하나만 진행 중이고, 다른 순서를 시작하면 앞선 것이 끝납니다
- 지연 시 뒤 순서 예상 시각 자동 재계산(SPEC 8.6). 누적 지연과 끝 예상 시각 표시
- 가로 타임라인 보기와 목록 보기. 종류는 색이 아니라 농도로 구분합니다
- 계산은 `packages/shared/src/schedule`에 순수 함수로 두고 테스트로 덮습니다

남은 것

- 순서를 끌어서 옮기기. 지금은 위로·아래로 단추로만 바꿉니다.
- 배치도를 여러 장 두고 순서마다 다른 도면을 고르기. 연결 칸은 있지만 배치도가
  아직 한 장입니다.

## 5단계 — 로컬 서버와 실시간 동기화 (완료)

- `npm run host`로 호스트 서버 시작. 접속 주소와 역할별 코드를 그 화면에만 찍고,
  네트워크가 여럿이면 주소 목록을 보여 줍니다(`--address`로 고릅니다)
- 호스트가 배포 빌드를 함께 서빙하므로 다른 기기는 브라우저만 있으면 됩니다.
  접속 주소 QR은 호스트가 `/qr.svg`로 냅니다
- WebSocket 프로토콜(SPEC 9장), 역할별 6자리 코드, **서버에서** 권한 검사
- 끊기면 마지막 내용을 그대로 두고 자동으로 다시 붙습니다. 붙으면 전체 상태를
  다시 받습니다. 항목 단위 `rev` 충돌은 나중 것이 이기고 밀린 쪽에 알립니다
- 사설 IP 대역 제한, 접속 실패 잠금, 메시지 스키마·크기(64KB)·빈도 제한
- 운영자가 아닌 역할은 화면에서도 읽기 전용입니다(SPEC 9.5.1)
- 호스트를 껐다 켜도 같은 코드를 씁니다(`--file`로 저장한 공연 파일에 들어갑니다)
- **브라우저 창 두 개로 동시 접속 테스트**를 만들어 확인했습니다

남은 것

- 공지 보내기 UI는 6단계(대시보드)에서 붙입니다. 프로토콜과 서버는 끝났습니다.
- 호스트를 앱 안에서 시작하지는 못합니다. 터미널에서 `npm run host`를 칩니다.

## 6단계 — 대시보드와 공지 화면 (완료)

- 운영자 대시보드: 지금·다음 순서와 남은 시간, 누적 지연, 공지 보내기,
  보낸 공지의 확인 수, 접속 기기 목록. 순서 시작·종료 단추를 바로 둡니다
- 표시 화면 3종: 대기실(지금·남은 시간·다음·콜 타임), 스태프(전환 지시와 담당),
  무대 뒤 큐(순서 이름과 남은 시간만 아주 크게)
- 긴급 공지가 오면 화면 전체를 덮습니다. 확인을 누른 화면에서만 사라지고,
  운영자 화면에는 확인한 기기 수가 보입니다
- 운영 화면은 다크, 설계 화면은 기기 설정을 따릅니다(docs/design.md)
- 화면 꺼짐 방지(Wake Lock). 지원하지 않는 브라우저에서는 그냥 넘어갑니다
- 연결이 끊기면 마지막 내용을 그대로 두고 "연결 끊김"을 얹습니다
- 남은 시간은 **서버 시각 기준**이라 모든 기기가 같은 숫자를 봅니다

남은 것

- 공지 대상 고르기. 지금은 스태프와 표시 화면에 함께 보냅니다.
- 운영자가 남의 화면에서 공지를 강제로 내리는 기능. 확인 단추로만 닫힙니다.
